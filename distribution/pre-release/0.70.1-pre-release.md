## English

### Highlights
- CorsixTH **0.70.1** on Android (**ARM64** / `arm64-v8a` only).
- Modern toolchain: AGP 8.x, Gradle 8.9, Kotlin 2.0, NDK 27, C++17, **target/compile SDK 36**.
- Theme Hospital import via SAF (GOG / retail); engine via `game.zip`.
- Soft keyboard for player name and textboxes (IME bridge).
- **Community flavor**: no Firebase, Crashlytics, Analytics, or Play Games in the APK.

### What was done

| Area | Details |
|---|---|
| Phases 0–7 | Baseline, 0.70.1 bootstrap, data packaging, gameplay UI, save/load lifecycle, soft keyboard |
| Phase 8 | Android 14/15/16 hardening: SDK 36, SAF-only storage, exported components, HID receivers, edge-to-edge/cutout, 16 KB page-size support, backup rules |
| Phase 9 | `community` / `playstore` flavors; community APK builds without Google cloud SDKs or telemetry |
| Keyboard | IME via `GameActivity` EditText + `CthImeBridge`; empty-buffer backspace deletes pre-filled `PLAYER` |

### Keyboard fix (recap)
- **Problem:** Soft keyboard missing on “Player name”; `PLAYER` could not be deleted.
- **Fix:** `require("TH")` / `require("sdl")` in `window.lua`; EditText IME bridge; backspace forwarding; SDL `showTextInput` → GameActivity path.

### Not in this pre-release
- Phase 10 release engineering / Play Store publishing polish  
- SDL3 / MIDI (deferred)  
- Full automated device test matrix  

### Install notes
- **Pre-release**, typically debug-signed unless CI release secrets are configured.
- Theme Hospital original data still required (setup wizard / SAF).
- Prefer a clean install if upgrading from older debug builds.
