### Keyboard fix (this checkpoint)
- **Problem:** Soft keyboard never appeared on “Player name”; when it did, pre-filled `PLAYER` could not be deleted.
- **Cause:** `window.lua` used global `SDL` / `TH` (nil — modules are `require` locals), so IME calls never ran. Immersive `SurfaceView` also stole focus from SDL `DummyEdit`.
- **Fix:**
  - `require("TH")` / `require("sdl")` in `window.lua`; request IME on textbox activate/tick
  - `GameActivity` EditText IME bridge + `CthImeBridge` → SDL text/backspace
  - Backspace on empty IME buffer forwards deletes into the in-game textbox
  - SDL `showTextInput` prefers GameActivity soft-keyboard path

### Correctif clavier (ce jalon)
- **Problème :** le clavier n’apparaissait pas sur « Nom du joueur » ; une fois affiché, impossible d’effacer le `PLAYER` prérempli.
- **Cause :** `window.lua` appelait les globaux `SDL` / `TH` (inexistants — modules en `require` local), donc l’IME n’était jamais demandé. Le `SurfaceView` immersif volait aussi le focus à `DummyEdit` SDL.
- **Correction :**
  - `require("TH")` / `require("sdl")` dans `window.lua` ; demande IME à l’activation / tick du textbox
  - Pont `EditText` dans `GameActivity` + `CthImeBridge` → texte / retour arrière SDL
  - Retour arrière sur buffer IME vide transmis au textbox du jeu
  - `showTextInput` SDL privilégie le chemin clavier de `GameActivity`
